Come viene calcolato
Valore Base = (Visualizzazioni ÷ 1000) × CPM
Valore Engagement = (Like × valore like) + (Commenti × valore commento) + (Condivisioni × valore condivisione) + (Iscritti × valore iscritto)
Totale = Valore Base + Valore Engagement
Se la retention è attiva: Totale finale = Totale × (retention ÷ 100)
